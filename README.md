
# HealthNexus

A modern client based hospital management software built using MERN stack.

🌐 Features of HealthNexus

Responsive Web Pages
– Works seamlessly across devices (desktop, tablet, mobile).

Dynamic Dashboards
– Patients: Can view their appointments, test results, prescriptions, and health records.
– Doctors: Can manage patient records, upcoming appointments, and consultations.

Appointment Booking System
– Patients can schedule appointments with doctors.
– Integrated payment gateway for secure payments.
– Email notifications for confirmations & reminders.

Pharmacy Page
– Browse and purchase medicines online.
– Integrated with payment and possibly prescription management.

Lab Tests Page
– Users can book diagnostic/lab tests.
– Test updates/results can be shown through dashboard integration.

Admin Dashboard
– Centralized control for managing patients, doctors, appointments, pharmacies, and labs.
– Analytics and reports for better decision-making.

## Installation

Clone / Download the project.

Run following command to install dependencies
```bash
npm install dependencies
```
or just
```bash
npm i
```
    
## Run Locally

Start the server in both frontend and backend folder

```bash
  npm run dev
```
